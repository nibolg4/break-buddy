# BreakBuddy

Напоминалка о перерывах для macOS, живёт в строке меню. В отличие от помодоро-таймеров, считает реальную активность: движение мыши, клики, прокрутку и клавиатуру. Если ты ушёл на митинг или обед, это засчитывается как перерыв, и отсчёт начинается заново.

## Как работает

- Раз в 5 секунд приложение спрашивает у macOS время с последнего действия пользователя (`CGEventSource.secondsSinceLastEventType`). Специальные разрешения не нужны.
- Если 5 минут подряд ничего не происходит (или Mac спал), включается режим перерыва 💤.
- Когда ты возвращаешься, начинается новая рабочая сессия.
- Через 50 минут работы без перерыва появляется окно со звуком: «Ещё 5 мин», «Ещё 15 мин», «Иду отдыхать».
- Если окно игнорировать, каждые 5 минут снова играет звук и окно встряхивается.

Значок в меню: `⏱ N` — минут без перерыва, `☕ N` — пора отдохнуть, `💤` — перерыв, `⏸` — пауза.

Настраиваются в меню: интервал напоминания (25–90 мин), длина перерыва (2–10 мин), «Не беспокоить 1 час», запуск при входе.

## Сборка

Нужны macOS 13+ и Xcode Command Line Tools (`xcode-select --install`).

```sh
./build.sh           # собрать в build/BreakBuddy.app
./build.sh install   # собрать, поставить в ~/Applications и запустить
```
